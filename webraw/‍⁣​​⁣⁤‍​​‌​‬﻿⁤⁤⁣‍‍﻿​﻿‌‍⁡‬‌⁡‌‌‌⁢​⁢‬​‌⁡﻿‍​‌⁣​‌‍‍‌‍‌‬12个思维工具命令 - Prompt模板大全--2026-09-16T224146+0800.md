1.

核心定义

Internet Vin（@internetvin）开发的一套自定义 Claude Code slash 命令，把 Claude 从「通用助手」变成「深度个性化思维伙伴」——能够追踪思想演化、发现潜在模式、压力测试信念，全部基于 Obsidian vault 中积累的个人笔记。

2.

关键前提

•

Obsidian CLI 让 Claude Code 不只能读文件，还能看到文件之间的链接关系

•

写作是燃料：vault 里积累的笔记越多，这些命令能做的事就越强大

•

人写 vs AI 写严格分离：保持 vault 中哪些是自己写的、哪些是 AI 生成的，这个界限非常重要

3.

完整命令列表（12 个）

上面是英文版，下面是中文版

日常操作类

/context — 加载全量上下文

读取 vault，汇总当前项目、近期反思、过去 7 天提到的优先事项。每次开始工作前跑一次，免去重新解释背景。

英文版

Plain Text

Read my vault and summarize my current context. Include active projects, recent reflections, and any priorities I've mentioned in the last 7 days.

中文版

Plain Text

读取我的 vault，总结我当前的状态。包括：进行中的项目、近期的反思记录、过去 7 天里我提到的优先事项。

/today — 晨间规划

拉取日历、任务、日记，整合成当天优先行动计划。早上迷茫不知从哪里开始时用。

Code block

Plain Text

Read my daily note, calendar, and task list. Generate a prioritized plan for today based on what I've said is important this week.

Code block

Plain Text

读取我今天的日记、日历和任务清单，根据我这周说过的重要事项，生成今天的优先行动计划。

/closeday — 日终复盘

总结今天进展，捕捉新想法，记录未完成事项带入明天。

Code block

Plain Text

Review what I worked on today. Summarize progress, capture any new ideas that came up, and note anything unfinished that should carry over to tomorrow.
