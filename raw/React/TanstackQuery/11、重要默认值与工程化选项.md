# 重要默认值与工程化选项

> **版本基线**：`@tanstack/react-query` **v5.104.x**。
> 官方文档：<https://tanstack.com/query/v5/docs/framework/react/guides/important-defaults> · <https://tanstack.com/query/v5/docs/framework/react/guides/retries> · <https://tanstack.com/query/v5/docs/framework/react/guides/polling> · <https://tanstack.com/query/v5/docs/framework/react/guides/network-mode>

## 一、Important Defaults（必须背）

| 默认项 | 默认值 | 调整方式 |
|---|---|---|
| 缓存数据新鲜度 | **视为 stale** | `staleTime` |
| 自动重拉时机 | 挂载新实例 / 窗口聚焦 / 网络重连 | `refetchOnMount` / `refetchOnWindowFocus` / `refetchOnReconnect` |
| 不活跃查询 GC | `5 * 60 * 1000` | `gcTime` |
| 失败重试 | **3 次**（指数退避） | `retry` / `retryDelay` |
| 引用稳定 | 结构化共享（structural sharing） | `structuralSharing` |
| 成功数据 | resolve 值 | 不能为 `undefined`（用 `null`） |

### 手动刷新开关

```ts
useQuery({
  queryKey: ['todos'],
  queryFn: fetchTodos,
  refetchOnMount: false,       // 挂载时不自动重拉
  refetchOnWindowFocus: false, // 切回窗口不重拉
  refetchOnReconnect: false,   // 网络重连不重拉
})
```

| 取值 | 含义 |
|---|---|
| `true` | 过期数据才重拉（默认，v5 由 stale 决定） |
| `false` | 不自动重拉 |
| `'always'` | 无论新鲜与否都重拉 |

## 二、Retry 重试机制

默认失败**静默重试 3 次**，指数退避延迟。

```ts
useQuery({
  queryKey: ['todos'],
  queryFn: fetchTodos,
  retry: 3,                    // 次数
  retry: true,                 // 无限重试
  retry: (failureCount, error) => failureCount < 2 && error.code !== 401, // 自定义
  retryDelay: attempt => Math.min(1000 * 2 ** attempt, 30000), // 指数退避
})
```

> **mutation 默认不重试**（`retry: 0`）。

## 三、轮询（Polling）：refetchInterval

与 staleTime 无关，按固定间隔持续刷新。

```ts
useQuery({
  queryKey: ['price'],
  queryFn: fetchPrice,
  refetchInterval: 5000,          // 每 5s 刷新
  refetchIntervalInBackground: true, // 窗口失焦也继续轮询（默认 false）
})
```

> `refetchInterval` 支持**函数**形式按数据动态决定：`(query) => query.state.data?.live ? 3000 : false`。

## 四、Network Mode 网络模式

控制查询在**离线/请求失败**时的行为。

| 取值 | 行为 |
|---|---|
| `online`（默认） | 在线才发请求；离线时 `fetchStatus` 变 `paused` |
| `always` | 无视网络状态，始终尝试请求 |
| `offlineFirst` | 优先走缓存/写操作，离线也能用乐观数据 |

```ts
useQuery({
  queryKey: ['todos'],
  queryFn: fetchTodos,
  networkMode: 'offlineFirst',
})
```

> 配合 `fetchStatus === 'paused'` 判断是否因离线暂停；重连后自动恢复（`refetchOnReconnect`）。

## 五、全局默认配置

把常用默认提到 `QueryClient` 级别，避免逐查询重复：

```ts
const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 60 * 1000,
      gcTime: 10 * 60 * 1000,
      retry: 2,
      refetchOnWindowFocus: false,
      retryDelay: attempt => Math.min(1000 * 2 ** attempt, 30000),
    },
    mutations: {
      retry: 1,
    },
  },
})
```

## 六、工程化组合建议

| 需求 | 配置 |
|---|---|
| 请求不过期 | `staleTime: Infinity` |
| 运行期不可变数据 | `staleTime: 'static'`（连失效都拦） |
| 实时行情 | `refetchInterval: n` |
| 弱网/离线 | `networkMode: 'offlineFirst'` |
| 关闭所有自动刷新 | 三个 `refetchOn*: false` |
| 全局统一刷新策略 | `QueryClient.defaultOptions` |
