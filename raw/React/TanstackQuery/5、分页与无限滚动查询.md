# 分页与无限滚动查询

> **版本基线**：`@tanstack/react-query` **v5.104.x**。
> 官方文档：<https://tanstack.com/query/v5/docs/framework/react/guides/paginated-queries> · <https://tanstack.com/query/v5/docs/framework/react/guides/infinite-queries>

## 一、分页查询（Paginated Queries）

普通分页：**每次只加载当前页**，用 `page` 作为 key 的一部分。

### 基础写法

```tsx
function Todos({ page = 1 }) {
  const { isPending, data } = useQuery({
    queryKey: ['todos', page], // page 参与 key → 每页各自缓存
    queryFn: () => fetchTodos(page),
  })
  return data?.list.map(...)
}
```

> ⚠️ 把 `page` 放进 key 后，切页是「新查询」，会**重新进入 loading**。若想切页时**保留旧页数据**过渡，用 `placeholderData: keepPreviousData`（v5 已把 v4 的 `keepPreviousData` 合并进 `placeholderData`）。

### v5 保留上一页数据（Lagged Query）

```ts
import { keepPreviousData } from '@tanstack/react-query'

const { isPending, isPlaceholderData, data } = useQuery({
  queryKey: ['todos', page],
  queryFn: () => fetchTodos(page),
  placeholderData: keepPreviousData, // 切页时先用上一页数据占位
})
```

| 字段 | 切页时表现 |
|---|---|
| `isPlaceholderData` | 为 true（当前数据来自占位/上一页） |
| `isPending` | 为 false（有占位数据，不闪 loading） |
| `isFetching` | 为 true（后台拉新页） |

> 常配合「禁用上一页/下一页按钮」逻辑：`disablePrev = page === 0`、`disableNext = isPlaceholderData`。

## 二、无限滚动查询（Infinite Queries）

用于**列表持续追加**（下拉加载 / 加载更多）。`useInfiniteQuery` 的 queryFn 会收到 `pageParam`。

### 核心返回结构

| 字段 | 说明 |
|---|---|
| `data.pages` | 数组，每一页的数据 |
| `data.pageParams` | 数组，每一页对应的 `pageParam` |
| `hasNextPage` | 是否还有下一页 |
| `isFetchingNextPage` | 正在加载下一页 |
| `fetchNextPage` | 加载下一页（用 `getNextPageParam` 算参数） |
| `fetchPreviousPage` | 加载上一页 |
| `isFetchingPreviousPage` | 正在加载上一页 |

### 基础示例（游标分页）

```tsx
import { useInfiniteQuery } from '@tanstack/react-query'

const {
  data, isLoading, isError, error,
  hasNextPage, isFetchingNextPage, fetchNextPage,
} = useInfiniteQuery({
  queryKey: ['projects'],
  queryFn: ({ pageParam }) => fetchProjects(pageParam),
  initialPageParam: 0, // v5 必填
  getNextPageParam: (lastPage) => lastPage.nextCursor, // 返回 undefined 即无下一页
  // 可选：getPreviousPageParam: (firstPage) => firstPage.prevCursor
})

// 渲染：把 pages 扁平化
const projects = data?.pages.flatMap(p => p.list) ?? []

// 加载更多
<button
  onClick={() => fetchNextPage()}
  disabled={!hasNextPage || isFetchingNextPage}
>
  {isFetchingNextPage ? '加载中...' : hasNextPage ? '加载更多' : '没有更多了'}
</button>
```

### v5 关键点：`initialPageParam` 必填

v5 的无限查询**必须**提供 `initialPageParam`（首页参数），否则类型/运行时报错。逻辑：

```
getNextPageParam(lastPage) → 算出「下一页要用的 pageParam」
首次请求用 initialPageParam 作为 pageParam
```

### `maxPages`：限制缓存页数（v5 新增）

```ts
useInfiniteQuery({
  queryKey: ['projects'],
  queryFn: ({ pageParam }) => fetchProjects(pageParam),
  initialPageParam: 0,
  getNextPageParam: lastPage => lastPage.nextCursor,
  maxPages: 5, // 只保留最近 5 页，旧页自动丢弃，避免缓存无限膨胀
})
```

> v5 新增 `maxPages`，取代了 v4 里 `refetchPage` 的复杂用法，避免大列表下缓存与请求失控。

### `useSuspenseInfiniteQuery`

配合 Suspense 的无限查询版本（详见第 13 篇）：

```ts
const { data, fetchNextPage, hasNextPage } = useSuspenseInfiniteQuery({
  queryKey: ['projects'],
  queryFn: ({ pageParam }) => fetchProjects(pageParam),
  initialPageParam: 0,
  getNextPageParam: lastPage => lastPage.nextCursor,
})
```

## 三、场景选择

| 场景 | 用哪个 |
|---|---|
| 翻页按钮、页码切换 | `useQuery` + `page` 进 key |
| 翻页但想保留旧页过渡 | `useQuery` + `placeholderData: keepPreviousData` |
| 下拉无限加载 | `useInfiniteQuery` |
| 表格虚拟滚动加载更多 | `useInfiniteQuery` + 虚拟化 |
