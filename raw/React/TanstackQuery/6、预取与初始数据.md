# 预取与初始数据

> **版本基线**：`@tanstack/react-query` **v5.104.x**。
> 官方文档：<https://tanstack.com/query/v5/docs/framework/react/guides/prefetching> · <https://tanstack.com/query/v5/docs/framework/react/guides/initial-query-data> · <https://tanstack.com/query/v5/docs/framework/react/guides/placeholder-query-data>

## 一、预取（Prefetching）

在数据真正被 `useQuery` 用到之前，**提前把数据写入缓存**，让页面秒开。

### `queryClient.prefetchQuery`

```ts
import { queryOptions } from '@tanstack/react-query'

const todoOptions = queryOptions({
  queryKey: ['todos'],
  queryFn: fetchTodos,
})

// 任意位置（事件回调、路由加载、首屏）触发
await queryClient.prefetchQuery(todoOptions)
```

之后组件里 `useQuery(todoOptions)` 会**直接命中缓存**，不再请求、不闪 loading。

> `prefetchQuery` 失败**不会抛错**（只打印 console.error），默认不会让预取错误污染页面。可通过 `{ retry: ... }` 等选项控制。

### `usePrefetchQuery`（v5 新增，组件内预取）

在**渲染期间**触发预取，适合路由级/布局级预取（v5.53+）：

```tsx
import { usePrefetchQuery } from '@tanstack/react-query'

// 组件渲染时就会去预取
usePrefetchQuery({ queryKey: ['todos'], queryFn: fetchTodos })
```

## 二、初始数据（initialData）：用现有数据初始化

`initialData` 提供**查询首次挂载时的同步初值**，来源通常是**另一份已知数据**（另一 query 的结果、外部状态）。初值**会被写入缓存**。

```ts
const [user, setUser] = useState<User>()

const query = useQuery({
  queryKey: ['user', userId],
  queryFn: () => fetchUser(userId),
  initialData: user, // 复用已有用户对象作为初始数据
})
```

### 区别：`initialData` vs `placeholderData`

| 维度 | `initialData` | `placeholderData` |
|---|---|---|
| 是否写入缓存 | **是**（成为正式缓存） | **否**（仅展示占位） |
| 是否持久化（gcTime 内） | 是 | 否 |
| 是否影响 staleTime | **有默认规则**（见下） | 不影响 |
| 用于「复用另一查询结果」 | 是 | 否 |
| 用于「切页保留旧数据」 | 不适合 | 是（`keepPreviousData`） |

> ⚠️ `initialData` 默认**使用 `staleTime` 的默认值**（若未设 staleTime 则为 0，即立即过期）。可用 `initialDataUpdatedAt` 指定该数据的时间戳来参与新鲜度判断。

```ts
useQuery({
  queryKey: ['user', userId],
  queryFn: () => fetchUser(userId),
  initialData: () => userCache.get(userId), // 函数形式可避免每次渲染重建
  initialDataUpdatedAt: userCache.updatedAt, // 告诉库这个初值多"新"
})
```

## 三、占位数据（placeholderData）：仅填充 UI

`placeholderData` 用于**同步填充展示**，但**不进缓存**、不影响缓存新鲜度，常在「切页/切筛选」时避免闪烁。

```ts
useQuery({
  queryKey: ['todos', filter],
  queryFn: () => fetchTodos(filter),
  placeholderData: (prev) => prev, // 切 filter 时先用上一份数据占位
})
```

### v5 合并了 keepPreviousData

v5 已把 v4 的 `keepPreviousData` 移入 `placeholderData`，直接用：

```ts
import { keepPreviousData } from '@tanstack/react-query'

useQuery({
  queryKey: ['todos', page],
  queryFn: () => fetchTodos(page),
  placeholderData: keepPreviousData,
})
```

## 四、三兄弟对比速查

| 机制 | 缓存写入 | 触发时机 | 典型用途 |
|---|---|---|---|
| `prefetchQuery` / `usePrefetchQuery` | 是 | 使用前主动 | 路由预取、首屏提速 |
| `initialData` | 是 | 挂载时 | 复用已有已知数据 |
| `placeholderData` | 否 | 展示时 | 切页/筛选避免闪烁 |
