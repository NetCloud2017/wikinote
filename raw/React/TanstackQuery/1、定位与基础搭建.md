# 定位与基础搭建

> **版本基线**：`@tanstack/react-query` **v5.104.x**（当前最新稳定版 5.104.5，暂无 v6）；涉及 Next.js 内容以 **Next.js 16** 为基线。
> 官方文档：<https://tanstack.com/query/v5/docs/framework/react/overview>

## 一、TanStack Query 是什么

TanStack Query（前身 React Query）被描述为 Web 应用「缺失的数据请求库」，本质是帮你解决 **服务端状态（server state）** 的「获取 / 缓存 / 同步 / 更新」。

它**不是**通用状态管理库。传统状态库（Redux、Zustand、Pinia）擅长**客户端状态**（组件内存中的 UI 数据），但对**异步服务端状态**处理很差。

### 服务端状态 vs 客户端状态

| 维度 | 客户端状态 | 服务端状态 |
|---|---|---|
| 存储位置 | 组件内存 / 本地 | 远程服务器（你未必拥有或控制） |
| 获取方式 | 同步 | 异步 API |
| 数据归属 | 本组件 | 多组件共享、可被他人更改 |
| 是否易过期 | 一般不会 | 随时可能过期 |
| 典型例子 | 弹窗开关、表单值、主题 | 用户列表、订单、文章 |

### 它帮你解决的核心问题

- **缓存**（编程中最难的事之一）
- **去重**：多个组件请求同一数据，合并为一次真实请求
- **后台刷新过期数据**
- 判断数据何时过期（stale）
- 尽快把更新反映到 UI
- 分页、懒加载等性能优化
- 内存与垃圾回收（gcTime）
- 结构化共享（structural sharing）做引用稳定，配合 `useMemo`/`useCallback`

## 二、三大核心概念

Quick Start 官方明确三大核心概念：

| 概念 | Hook / API | 用途 |
|---|---|---|
| **Queries（查询）** | `useQuery` | 获取数据（GET 类） |
| **Mutations（变更）** | `useMutation` | 创建/更新/删除数据（POST/PUT/DELETE 类副作用） |
| **Query Invalidation（失效）** | `queryClient.invalidateQueries` | 主动让查询过期并重新请求 |

## 四、基础搭建：QueryClient + QueryClientProvider

`QueryClient` 是所有查询的容器（缓存 + 配置）。用一个实例包住应用根节点：

```tsx
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'

// 建议放在模块顶层，避免每次渲染新建导致缓存丢失
const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 5 * 60 * 1000, // 全局默认
    },
  },
})

export default function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <TodoApp />
    </QueryClientProvider>
  )
}
```

### 最小可用示例（核心三件套）

```tsx
import { useQuery } from '@tanstack/react-query'

function RepoStats() {
  const { isPending, error, data } = useQuery({
    queryKey: ['repoData'],
    queryFn: async () => {
      const res = await fetch('https://api.github.com/repos/TanStack/query')
      if (!res.ok) throw new Error('Failed to fetch')
      return res.json()
    },
  })

  if (isPending) return <span>Loading...</span>
  if (error) return <span>错误：{error.message}</span>
  return <div>{data.name} ⭐ {data.stargazers_count}</div>
}
```
