# 8. 最小可跑骨架

一套 `pnpm + Turborepo + Changesets` 的最小可跑结构。

## 目录结构

```
my-monorepo/
├── apps/
│   └── web/                    # Next.js 应用
│       ├── package.json        # name: "@acme/web"
│       ├── tsconfig.json
│       └── ...
├── packages/
│   ├── ui/                     # @acme/ui 组件库
│   │   ├── src/
│   │   ├── package.json
│   │   └── tsconfig.json
│   ├── utils/                  # @acme/utils 工具函数
│   │   ├── src/
│   │   ├── package.json
│   │   └── tsconfig.json
│   └── tsconfig/               # @acme/tsconfig 共享 tsconfig
│       ├── base.json
│       ├── nextjs.json
│       ├── node.json
│       └── package.json
├── .changeset/
│   └── config.json
├── .gitignore
├── pnpm-workspace.yaml
├── turbo.json
├── package.json                # 根 package.json
└── pnpm-lock.yaml
```

## `pnpm-workspace.yaml`

```yaml
packages:
  - 'apps/*'
  - 'packages/*'
```

## 根 `package.json`

```jsonc
{
  "name": "acme-monorepo",
  "private": true,
  "packageManager": "pnpm@9.0.0",
  "scripts": {
    "build": "turbo run build",
    "dev": "turbo run dev",
    "lint": "turbo run lint",
    "test": "turbo run test",
    "changeset": "changeset",
    "version-packages": "changeset version",
    "release": "turbo run build && changeset publish"
  },
  "devDependencies": {
    "turbo": "^2.0.0",
    "@changesets/cli": "^2.27.0"
  }
}
```

## `turbo.json`

```jsonc
{
  "$schema": "https://turbo.build/schema.json",
  "tasks": {
    "build": {
      "dependsOn": ["^build"],
      "outputs": ["dist/**", ".next/**"]
    },
    "dev": {
      "cache": false,
      "persistent": true
    },
    "lint": {},
    "test": {
      "dependsOn": ["build"]
    }
  }
}
```

关键点：
- `^build` = 先 build 上游依赖包，自动处理构建顺序
- `outputs` = 缓存产物目录
- `dev` 设 `persistent: true`，Turbo 知道这是长驻进程

## 内部包互相引用

```jsonc
// packages/ui/package.json
{
  "name": "@acme/ui",
  "version": "0.1.0",
  "main": "./dist/index.js",
  "types": "./dist/index.d.ts",
  "scripts": {
    "build": "tsup",
    "dev": "tsup --watch",
    "lint": "eslint src"
  },
  "dependencies": {
    "@acme/utils": "workspace:*"
  },
  "devDependencies": {
    "@acme/tsconfig": "workspace:*",
    "tsup": "^8.0.0",
    "typescript": "^5.4.0"
  }
}
```

## `.changeset/config.json`

```jsonc
{
  "$schema": "https://unpkg.com/@changesets/config@3.0.0/schema.json",
  "changelog": "@changesets/cli/changelog",
  "commit": false,
  "fixed": [],
  "linked": [],
  "access": "public",
  "baseBranch": "main",
  "updateInternalDependencies": "patch",
  "ignore": ["@acme/web"]
}
```

## 启动

```bash
# 1. 装依赖
pnpm install

# 2. 开发（并行起所有 dev）
pnpm dev

# 3. 只起 web，并 watch 它依赖的 ui/utils
pnpm dev --filter=@acme/web...

# 4. 构建
pnpm build

# 5. 加 changeset
pnpm changeset

# 6. 发版
pnpm release
```
