# 形参、实参、值传递和引用传递

## 1、形参和实参

**形参（形式参数）**：定义函数时，函数名后面括号里列的参数。它本质是函数内部的局部变量，只有在函数被调用时才会被分配内存，函数执行完就销毁。

**实参（实际参数）**：调用函数时，真正传给函数的值。

```javascript
function add(a, b) {
    // a、b 是形参
    return a + b;
}
add(1, 2); // 1、2 是实参
```

要点：

- 形参数量和实参数量可以不一致：
  - 形参多、实参少：没传的形参值为 `undefined`
  - 实参多、形参少：多传的实参不会被形参接收，要通过 `arguments` 取

```javascript
function fn(a, b) {
    console.log(a, b);        // 1 undefined
    console.log(arguments);   // [1, 2, 3] 类数组对象
}
fn(1, 2, 3);
```

## 2、值传递和引用传递

先记住一句话：**JavaScript 中所有函数参数的传递方式，统一都是「值传递」**。

区别在于：这个"值"到底是什么。

### 2.1 基本类型 —— 值传递

基本类型（Number、String、Boolean、Undefined、Null、Symbol、BigInt）存储的就是值本身。

传给函数时，会**复制一份值**给形参。形参和实参是两个互不干扰的变量，函数内部怎么改都不会影响外部。

```javascript
function change(n) {
    n = 100;
    console.log("函数内：", n);   // 100
}

let a = 1;
change(a);
console.log("函数外：", a);       // 1 （不受影响）
```

内存示意：

```
a ──→ 1
n ──→ 1  （复制出来的副本，各管各的）
```

### 2.2 引用类型 —— 共享传递（Pass by Sharing）

对象、数组、函数等引用类型，变量里存的不是对象本身，而是**指向对象的引用地址（指针）**。

传给函数时，复制的是这个**地址**，而不是对象本身。于是形参和实参指向了堆里的**同一个对象**。

所以分两种情况：

```javascript
// 情况一：通过形参修改对象的属性 → 会影响原对象
function changeName(obj) {
    obj.name = "new";
}
let o = { name: "old" };
changeName(o);
console.log(o.name);   // "new"  （被改了）
```

```javascript
// 情况二：把形参整个重新赋值 → 不会影响原对象
function reassign(obj) {
    obj = { name: "new" };   // 局部变量 obj 指向了一个新对象
}
let o2 = { name: "old" };
reassign(o2);
console.log(o2.name);   // "old"  （没被改）
```

内存示意：

```
// 情况一：
o ──┐
    ├──→ { name: "old" }  ← 修改属性时，两边看到的是同一个对象
obj ┘

// 情况二：
o2 ────→ { name: "old" }
obj ───→ { name: "new" }  ← 局部变量 obj 指向了新对象，跟 o2 脱钩
```

> 为什么不叫"引用传递"？
> 真正的引用传递（Pass by Reference）是指：函数内部对形参整体重新赋值，外部变量也会跟着改。JS 做不到这一点，所以严格来说 JS 是 **Pass by Sharing（共享传递）**，不是真正的引用传递。但面试和日常口语里说"对象是引用传递"，大家都懂这个意思。

## 3、对比总结

| 对比项 | 基本类型 | 引用类型 |
| --- | --- | --- |
| 存储位置 | 栈内存 | 栈里存地址，堆里存对象 |
| 传的是什么 | 值的副本 | 地址的副本 |
| 改形参的值 | 不影响外部 | 不影响外部 |
| 通过形参改对象属性 | 不存在 | 会影响外部 |
| 常见类型 | Number、String、Boolean、Undefined、Null、Symbol、BigInt | Object、Array、Function、Date、RegExp |

## 4、避坑速记清单

1. **JS 没有真正的引用传递**，对象传参传的是"地址的副本"，所以重新赋值形参不会改到外部变量。
2. **想在函数里安全地改对象而不污染原对象**，先浅拷贝/深拷贝一份再操作（参见《浅拷贝和深拷贝》）。
3. **`arguments` 是类数组，不是真数组**，没有 `forEach`、`map` 这些方法，要用得先 `Array.from(arguments)` 或 `[...arguments]`。
4. **严格模式下，`arguments` 和形参不同步**；非严格模式下，改形参会同步改 `arguments[i]`，改 `arguments[i]` 也会同步改形参。
5. **`const` 声明的对象也能改属性**——`const` 锁的是引用地址，不是对象内容。
6. **判断类型用 `typeof` 会把 `null` 判成 `"object"`、把数组判成 `"object"`**，精确判断用 `Object.prototype.toString.call(x)`。
7. **函数参数默认值有独立作用域**，默认值表达式里不能直接访问函数体内部的其他变量。

## 5、小测试（先自己答，再往下看）

```javascript
function fn(x, obj) {
    x = x * 2;
    obj.value = obj.value * 2;
    obj = { value: 1 };
}
let a = 10;
let b = { value: 10 };
fn(a, b);
console.log(a);    // ?
console.log(b.value);  // ?
```

<details>
<summary>点击看答案</summary>

- `a` 是基本类型，值传递，函数内改的是副本 → **`a` 还是 10**
- `b` 是对象，传的是地址副本。`obj.value = ...` 改的是同一个对象的属性 → `b.value` 变成 20
- 后面 `obj = { value: 1 }` 只是让局部变量 `obj` 指向新对象，跟 `b` 脱钩，不影响 `b`
- 所以：**`a = 10`，`b.value = 20`**

</details>
