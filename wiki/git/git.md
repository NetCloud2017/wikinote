## Overview

这一页整理 Git 基础命令、分支操作、提交历史和协作场景中的常用手册。

## 基础模型

- 工作区、暂存区和提交历史是 Git 的三个核心层次。
- 提交记录表示项目快照，分支是指向提交的可移动引用。
- 远程仓库用于共享、同步和协作，拉取与推送需要理解分叉和冲突。

## 常用操作

- 初始化、克隆、查看状态、暂存和提交构成日常工作流。
- 分支创建、切换、合并和变基用于组织变更历史。
- 查看日志、差异、引用和文件历史有助于定位变化。
- 回退、撤销和重置属于高风险操作，应先确认目标提交和影响范围。

## 协作注意点

- 提交应保持主题单一，信息应说明变更目的。
- 拉取后出现冲突时，先理解双方改动，再逐块解决并验证。
- 不要覆盖他人的未提交改动，也不要对共享历史执行未经协调的重写。
