## Overview

这一页整理浏览器开发者工具、VS Code、Vim、Neovim、tmux、GitHub、搜索引擎技巧和油猴脚本。

## 浏览器与编辑效率

- Chrome 开发者工具用于查看网络、元素、控制台、性能和调试信息。
- VS Code 快捷键与 EditorConfig 关注编辑效率和跨项目格式一致。
- GitHub 快捷键和访问优化用于减少重复操作。
- 百度与 Bing 高级搜索技术用于精确限定站点、标题、文件类型和关键词。

## 终端编辑环境

- Vim 和 Neovim 都以模式编辑和可组合命令为核心。
- Neovim 使用 Lua 配置插件和核心选项，适合构建可维护的终端编辑环境。
- tmux 用于终端复用、会话保持、分屏和窗口管理。
- 编辑器配置应围绕实际操作频率组织，避免堆叠未使用的插件。

## 浏览器脚本

- 油猴脚本可以扩展网页行为，常用于注入样式、自动操作和界面增强。
- 用户脚本涉及页面结构变化、安全边界和站点条款，需要谨慎维护选择器与权限。
