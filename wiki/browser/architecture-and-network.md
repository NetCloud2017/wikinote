## Overview

这一页整理浏览器多进程架构、TCP 与 UDP、请求发起流程和 HTTP 响应码。它描述用户输入 URL 后，浏览器如何解析、建立连接并接收响应。

## 浏览器架构

- 浏览器由多个进程和线程协作，渲染、网络、GPU 和插件职责分离。
- 多进程架构提升隔离和稳定性，但也带来进程管理、内存和通信成本。
- 旧版浏览器原理笔记与新版目录内容属于同一主题，合并阅读可减少重复。

## 网络传输

- TCP 面向连接，强调可靠传输、顺序和流量控制。
- UDP 不建立连接，开销更小，但不保证到达和顺序。
- DNS、连接建立、请求发送、响应接收和连接复用共同构成网络请求链路。

## HTTP 响应

- 响应码按信息、成功、重定向、客户端错误和服务端错误分组。
- 状态码只描述服务端处理结果，具体业务错误仍需接口契约表达。
- 网络排查需要结合请求时间线、缓存、DNS 和连接状态。
