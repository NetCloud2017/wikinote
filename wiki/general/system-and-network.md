## Overview

这一页整理 Windows 命令、文件名批量处理、存储单位、DNS 服务地址和 hosts 文件。

## Windows 与文件操作

- Windows 运行窗口和命令行可以快速打开目录、工具和控制面板。
- 文件名批量处理适合统一编号、替换文本和整理资源。
- 终端相关原始文件为空，已作为无内容资料记录。

## DNS 与 Hosts

- DNS 服务地址用于域名解析，不同服务在速度、隐私和可靠性上存在差异。
- hosts 文件可以把域名映射到指定 IP，常用于本地开发、测试和临时绕过 DNS。
- 修改 hosts 后可能需要刷新 DNS 缓存。
- 域名解析问题应结合 DNS、hosts、代理和网络环境排查。

## 数据单位

- bit、byte、KB、MB 等单位用于描述存储和传输规模。
- 存储容量与网络速率的时间单位不同，需要区分大小写和换算语境。
