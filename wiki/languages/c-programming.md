## Overview

这一页整理 C 语言数据类型、宏定义和算术运算符。

## 数据类型

- C 语言的基本类型、修饰符、取值范围和存储大小与平台相关。
- 宏定义在预处理阶段替换文本，需注意括号、副作用和类型安全问题。
- 变量声明、初始化和作用域共同决定程序行为。

## 运算符

- 算术运算符遵循优先级和结合性。
- 整数除法、取模、类型转换和溢出是常见错误来源。
- 表达式求值顺序可能影响带有副作用的代码。

## 使用边界
